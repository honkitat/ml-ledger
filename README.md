# Martin Luk 2026 — trade ledger

Interactive ledger of Martin Luk's 2026 livestream trade events, built from 98 archived streams,
cross-checked against the official USIC standings and his broker-linked Kinfo profile.

- `index.html` — the browsable ledger (single file, no dependencies)
- `files/ML_2026_forensic_review.pdf` — the written review
- `files/ML_2026_ledger.xlsx` — events, round trips, monthly series, rule statements
- `files/events.csv`, `files/round_trips.csv` — flat data
- `CHANGELOG.md` — what changed in each published version

Not indexed by search engines. Prices shown are the stream date's daily OHLC from Yahoo; they bracket
the fill, they are not his fill. No event is screen-verified (video is unreachable from the build host).

Sources: financial-competitions.com (official USIC monthly standings), kinfo.com public profile,
archived livestream transcripts, Yahoo Finance daily bars.
